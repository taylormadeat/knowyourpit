# KnowYourPit custom icon assets

These six 1024 × 1024 PNGs are isolated, high-resolution raster exports with
transparent backgrounds and consistent canvas padding:

- `home.png` — plain house from the `...1245` source sheet
- `plan.png` — clipboard-plus from the `...1245` source sheet
- `cook-log.png` — checklist clipboard from the `...1248` source sheet
- `grill.png` — grill with flame from the `...1248` source sheet
- `probe-check.png` — clipboard with probe from the lower-left concept on the
  `...1246` source sheet
- `seasoning.png` — seasoning shaker from the `...1248` source sheet

The `...1248` and `...1249` sheets are byte-for-byte identical, so `...1248`
was used once for the three matching concepts. The pale and checkerboard
presentation backgrounds were removed during isolation; the charcoal outlines
and orange accents are retained.

All six concepts separated cleanly from their source sheets. These remain
raster artwork, so Illustrator vectorization is recommended if an infinitely
scalable master icon system is needed. No app navigation or icon integration
is included here.
